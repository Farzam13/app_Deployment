# ابزارهای هوشمند پزشکی دکتر کبیریزاده (اپلیکیشن اندروید)

اپلیکیشن اندروید ارزیابی هوشمند شاخص توده بدنی (BMI)، مقایسه روش‌های جراحی چاقی، رهگیری وزن، تغذیه بعد از عمل، بیمه، اقساط و ثبت مشاوره پزشکی.

## ویژگی‌ها
- **ارزیابی هوشمند BMI**: محاسبه دقیق شاخص توده بدنی، دسته‌بندی و مسیرهای درمانی (ASMBS/IFSO 2022).
- **۱۰ ابزار تعاملی**: شامل مقایسه جراحی چاقی، ارزیابی اولیه، رهگیری کاهش وزن، راهنمای تغذیه، استعلام بیمه، محاسبه‌گر اقساط، پیدا‌کردن مسیر و علائم هشدار.
- **ذخیره‌سازی محلی (Room Database)**: ثبت و مدیریت تاریخچه رهگیری وزن و درخواست‌های مشاوره پزشکی روی دستگاه.
- **طراحی مدرن Material Design 3 (M3)**: رابط کاربری فارسی راست‌چین (RTL)، رنگ‌بندی اختصاصی زرشکی-طلایی و آیکون تطبیقی.
- **پنل مدیریت ابزارها**: نمایش نسخه قواعد پزشکی سیستم (`medical-core-2026.07.26`) و مدیریت درخواست‌های ثبت‌شده.
